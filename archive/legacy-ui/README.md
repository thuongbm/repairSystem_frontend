# Giao diện mẫu cũ

Các trang và component trong thư mục này không được `src/App.jsx` sử dụng. Chúng được giữ lại để tham khảo các ý tưởng giao diện trước đây; một số thao tác dùng dữ liệu mẫu hoặc API cũ.

Khi dùng lại một phần, chuyển nó vào `src/features` tương ứng, cập nhật import và nối với API hiện hành. `npm run lint` bỏ qua thư mục lưu trữ này.
